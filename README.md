# MarblePlugin

Paper + Kotlin 기반 3D 도시형 보드게임 MVP.

## 요구 사항
- Java 25
- Gradle 8.14+ 또는 9.x
- Paper 26.3 API 계열
- IntelliJ IDEA 권장

## 빌드
프로젝트 폴더에서 `gradle build` 실행 (Gradle 8.14+ 또는 9.x 설치 필요)

산출물: `build/libs/MarblePlugin-0.1.0.jar`
빌드한 JAR을 서버 `plugins/` 폴더에 넣고 재시작하세요.

## 명령어
- `/마블` : GUI 열기
- `/마블 생성` : 현재 위치에 3D 보드 생성 (marble.admin)
- `/마블 참가`
- `/마블 나가기`
- `/마블 시작`
- 주사위: 현재 차례 플레이어에게 GUI가 자동으로 열리며, `🎲 주사위 직접 굴리기` 버튼을 클릭해야 진행됩니다. `/마블 주사위`는 GUI를 여는 안내 명령으로만 동작합니다.
- `/마블 구매`
- `/마블 패스`
- `/마블 정보`

## MVP 범위와 주의
보드 자동 생성, 참가/턴/주사위, 기본 구매/통행료, SQLite 저장을 포함하는 초기 코드 골격입니다.
원작의 세부 규칙 전체(더블, 인수, 독점, 세부 황금열쇠, 복잡한 파산 정산, 재접속 복구)는 아직 구현되지 않았습니다.
운영 서버 적용 전 별도 테스트 서버에서 검증하세요.

Paper API는 `26.3.build.+`를 사용하며 Java 25가 필요합니다.


## 3D 도시 보드 및 건물 건설
- 24칸 보드판의 타일 테두리를 폴리시드 안산암으로 정리하고, 도시/관광지 중앙을 현대적인 석재·조명 포인트로 변경했습니다.
- 내 소유 도시 또는 관광지에 도착하면 건설 선택 GUI가 자동으로 열립니다. `/마블 건설`로 다시 열 수도 있습니다.
- 도시 구매 직후에도 같은 차례에 별장을 건설할 수 있습니다.
- 첫 바퀴 완주 전에는 별장, 1회 완주 후에는 빌딩, 2회 완주 후에는 호텔까지 건설할 수 있습니다.
- 출발 칸에 정확히 도착하면 내 소유 도시/관광지 중 하나를 골라 건설할 수 있습니다.
- 건설 순서와 비용: 별장(1,500원) → 빌딩(3,000원) → 호텔(5,000원).
- 통행료(도시 구매 가격 기준): 건물 없음 10%, 별장 15%, 빌딩 25%, 호텔 40%.
- 예: 4,000원 도시라면 통행료는 건물 없음 400원, 별장 600원, 빌딩 1,000원, 호텔 1,600원입니다.
- 완주 횟수는 SQLite `players.laps_completed`에 저장되며, 기존 데이터베이스에는 새 컬럼이 자동 추가됩니다.
- 건설하지 않으려면 건설 GUI의 `건설하지 않고 턴 종료` 버튼 또는 `/마블 패스`를 사용합니다.
